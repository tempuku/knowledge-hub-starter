# Reviewless SHA-bound evidence gate: live positive fixture

Associated issue: https://github.com/tempuku/knowledge-hub-starter/issues/48
Acceptance parent: https://github.com/tempuku/knowledge-hub-starter/issues/42
Owner-approved review policy: https://github.com/tempuku/knowledge-hub-starter/issues/24#issuecomment-6819748012

This is a public-only Markdown fixture for a live GitHub merge-enforcement test.
It does not contain credentials, private knowledge records, or production state.
It is inert; the existing validation workflow and its browser/privacy steps remain enabled.

Acceptance evidence must refer to the exact PR head SHA and the actual GitHub Actions run.
The fixture does not itself establish CI success or a successful GitHub merge.
