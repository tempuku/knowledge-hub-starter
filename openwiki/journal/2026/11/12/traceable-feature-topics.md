# Traceable feature topics for agents — 2026-11-12

Reviewed open Knowledge Hub issues and approved design; opened [issue #46](https://github.com/tempuku/knowledge-hub-starter/issues/46).

The schema already provides kebab-case tags and the design includes search and URL-addressable filters. The missing piece is **feature-level traceability for agents** across canonical records, decisions, revisions, evidence and gaps, including cross-project queries.

Proposed: reuse tags such as `feature-calendar`, define stable naming/alias semantics, provide deterministic privacy-scoped MCP/CLI topic queries and shareable UI filtering. Preserve canonical IDs and append-only logs. Do not infer completion from tags alone.

**Status:** design discussion only. No schema change or implementation approved. Issue #46 holds dependencies and acceptance checklists.
