# Knowledge hub kickoff

Create a private Git-backed OKF v0.2 repository to record thoughts and projects, starting with the Ivanovo models work. Capture each dated item in a separate Markdown document. Build a day/week/month site from small date-sharded indexes and lazy-loaded individual entries, rather than parsing one unbounded global `log.md`. Git retains the audit trail; links preserve external evidence.
