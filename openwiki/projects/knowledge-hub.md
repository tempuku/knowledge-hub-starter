A private, Git-backed home for projects, ideas, and decisions. Initial entry: [kickoff record](../journal/2026/11/09/knowledge-hub-kickoff.md). Store dated records as atomic OKF concepts; generate a day/week/month static diary from date-sharded JSON. Current repository is a local starter package; no remote repository has yet been created.
